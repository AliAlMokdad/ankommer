How to install in Gmail
  1. Open Gmail Settings → General
  2. Scroll down to Signature → click + Create new
  3. Name it ANKOMMER
  4. In the editor, click the rendered preview above (NOT the HTML source) — select all (Ctrl+A or Cmd+A), copy (Ctrl+C / Cmd+C), and paste into the Gmail signature editor. The styling will carry over.
  5. Under Signature defaults, set ANKOMMER as the default for both FOR NEW EMAILS USE and ON REPLY/FORWARD USE
  6. Scroll to the bottom and click Save Changes
How to install in Outlook (web)
  1. Settings (gear icon) → View all Outlook settings → Mail → Compose and reply
  2. Email signature → New signature → name it ANKOMMER
  3. Copy the rendered preview above and paste into the editor
  4. Set as default for new and reply messages → Save
How to install in Apple Mail
  1. Mail → Settings → Signatures
  2. Add new signature → name it ANKOMMER
  3. Copy the preview above and paste into the signature box
  4. Drag the new signature onto your account in the left column
  5. Set Choose Signature dropdown at the bottom to ANKOMMER
